# Documentação do Projeto: Desafio Power BI - Analyst (DIO)

Este documento detalha a execução do desafio prático proposto no curso de Power BI da Digital Innovation One (DIO), focado na criação de visuais e organização de dados.

## 1. Objetivo do Desafio
O objetivo principal foi consolidar o conhecimento em criação de visuais, manipulação de campos e publicação de relatórios, utilizando a amostra de dados (Financial Sample) fornecida pela Microsoft via repositório GitHub.

## 2. Processamento de Dados
- **Fonte de Dados:** Repositório GitHub (Financial Sample).
- **Ferramenta:** Power BI Desktop.
- **Ações Realizadas:**
    - Importação do arquivo de dados.
    - Replicação de duas páginas de relatórios existentes para estudo de design e lógica.
    - Criação de uma terceira página personalizada com foco analítico geográfico e segmentado.

## 3. Estrutura da Página 3 (Visuais Criados)

A terceira página foi desenvolvida para oferecer uma visão global de desempenho, utilizando os seguintes componentes:

### Descrição dos Visuais
* **Visual Mapa 1 (Vendas por País):** Exibe a soma de vendas e unidades vendidas distribuídas geograficamente.
* **Visual Mapa 2 (Lucro por País):** Mapa focado especificamente na distribuição do lucro (*Profit*) por país.
* **Gráfico de Pizza (Lucro por Segmento):** Detalhamento da rentabilidade por segmento de mercado.

| Visual | Descrição | Campos Utilizados |
| :--- | :--- | :--- |
| **Mapa de Vendas** | Localização por país com métricas de volume. | Country, Sales, Units Sold |
| **Mapa de Lucro** | Focado na distribuição geográfica do lucro. | Country, Profit |
| **Gráfico de Pizza** | Distribuição de lucro por nicho de mercado. | Segment, Profit |

## 4. Melhores Práticas e Refinamentos
Para garantir a qualidade e o profissionalismo do dashboard, foram realizados os seguintes ajustes:

- **Renomeação de Títulos:** Títulos genéricos foram alterados para nomes diretos (ex: "Análise de Lucratividade Global").
- **Dicas de Ferramentas (Tooltips):** Configuração de campos extras para fornecer contexto ao passar o mouse sobre os visuais.
- **Design de Layout:** Organização simétrica para facilitar a leitura dos dados.

## 5. Entrega
- **Formato de Arquivo:** Projeto salvo em formato `.pbix`.
- **Publicação:** Relatório publicado no Power BI Service e integrado ao Power Point.
